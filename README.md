# OUTFIT合伙人 · 对话式穿搭推理智能体

2026秋软工实践团队作业（二）交付仓库。仓库分三块：

- `delivery/wardrobe-agent-交付包_20261108/`：可运行工程（FastAPI + SQLite + 单页前端 + 规则库 + 知识库 + 设计素材）
- `docs/说明书/`：系统设计说明书、数据库设计说明书 PDF
- `docs/第一次作业/`：需求规格说明书、用户调研报告、选题报告

## 快速开始

```bash
cd delivery/wardrobe-agent-交付包_20261108
pip install -r requirements.txt
uvicorn app.main:app --port 8300
# 浏览器打开 http://127.0.0.1:8300/docs
```

不配置任何密钥也能跑通推荐主链路；LLM 未接入时知识问答走 BM25 原文召回，推荐文案走模板。
