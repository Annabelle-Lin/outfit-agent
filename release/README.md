# release 目录说明

存放对外交付的 PDF。文件名必须与博客、作业提交里的名称一致。

## 文件命名

- `OUTFIT合伙人_系统设计说明书_v1.0.pdf`
- `OUTFIT合伙人_数据库设计说明书_v1.0.pdf`

## 导出检查

- [ ] 目录页码与实际页码一致
- [ ] 图号、表号连续，正文有引用
- [ ] 字体已嵌入（换一台电脑打开不乱码）
- [ ] 图片清晰，放大到 200% 不糊
- [ ] 页眉有文档名，页脚有页码
- [ ] 文件大小 < 50MB（超过用 GitHub Release 附件或云盘）
- [ ] 无痕窗口能下载/预览
