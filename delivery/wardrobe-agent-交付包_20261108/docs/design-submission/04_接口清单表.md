# 接口清单表

> 本表依据当前代码实际路由统计，共 34 个端点。除标注“免鉴权”的接口外，其余均需在请求头携带 `Authorization: Bearer <token>`。统一响应结构为 `{code, msg, data}`，业务成功 `code=0`。

> 实现状态口径：对话模块（序号 20–25）的完整多轮机制待确认、大模型未接入，当前以静态原型演示，表中为目标接口设计；其余模块接口为已实现。上传识别接口（序号 34）的视觉模型段未启用，当前走本地启发式。
