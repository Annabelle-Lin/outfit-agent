# 业务流程说明

## 一、账号与建档流程

用户首次使用时在认证视图切换到注册页签，填写昵称、账号与密码，系统校验账号唯一性后保存密码摘要并签发令牌，随后进入引导建档流程。用户在引导页填写性别、常用城市、身高、体型与常用风格，提交后形成个人画像。老用户直接登录，系统校验凭证后取回其衣物、反馈、评估与会话数据及统计信息。

## 二、衣橱管理流程

用户进入电子衣橱后，可通过新增弹窗逐件录入衣物，先选一级品类再联动选择二级品类，填写颜色、季节、合体度、面料、场合等属性并上传图片，提交后单品入库。也可下载模板后用 Excel 批量导入，系统逐行校验、成功行入库、失败行返回行号与原因。用户可按品类、颜色、季节、场合筛选衣物，对单品做编辑或删除，也可整柜清空。

## 三、对话推荐主流程（对话机制待确认，推荐内核已实现）

完整多轮对话机制当前待进一步确认，对话界面以静态原型演示；其中规则引擎推荐链路不依赖大模型，已实现。目标流程中，用户创建会话时，系统按“前端传入天气、用户常用城市实时天气、天气未知”的优先级确定天气来源，并初始化场合、约束与额度。用户在对话中表达需求，后端先判断是否需要澄清，场合与天气都缺失时先反问而不凭空假设；信息齐备后进入已实现的推荐链路，引擎枚举组合、硬过滤、排除已展示、打分、差异化取前三、生成理由并持久化方案快照。回复环节因大模型尚未接入，当前由本地模板组织；多轮调整（设置排除色、替换品类、临时偏好、单件替换）随对话机制确认后落地。

## 四、反馈与偏好学习流程

用户对方案给出喜欢、一般、不喜欢的评价并可附标签评论，系统记录反馈及其偏好增量，然后按该用户全部反馈重算五维长期偏好并写回。用户可在反馈影响清单中查看每条反馈的作用，也可撤销某条反馈，系统以墓碑标记跳过该记录后重新计算，分数精确回退。

## 五、知识问答流程

用户提出“为什么、怎么选、如何搭配”类问题时，系统在知识库中做混合检索召回相关片段，检索能力已实现。因大模型当前未接入，系统直接展示原文片段并标注来源；待模型接入后再结合对话上下文生成回答。该流程不消耗推荐额度。

## 六、购前评估流程

用户在评估页上传拟购单品图片或手工填写属性，系统补全推断的暖度与季节，按用户传入气温、城市实时天气或季节默认值确定温度，随后用与推荐相同的规则枚举含目标单品的合法搭配，计算可搭配套数、与现有单品的 Jaccard 重复度及自身合理性，给出建议购买、谨慎购买或不建议购买的结论，并保存评估记录。

## 七、会话与额度流程（随对话机制实现）

目标方案中，会话维护独立的推荐额度，初始十五次，推荐与换一批等动作按配置扣减，知识问答不扣减；每次动作先校验额度是否足够，不足时拦截并提示开启新对话。该流程与多轮对话机制一并确认后落地。用户可主动结束会话，也可在历史记录中回看历次会话与方案。
