# 数据字典

> 本字典依据 `app/db.py` 的 ORM 模型整理，共 7 张表。类型列同时给出 ORM 类型与 SQLite 物理类型含义；JSON 类型在 SQLite 中以文本存储，由 Pydantic 模型校验结构。

## 一、users 用户表

存储用户账号、体型、资料与长期偏好。主键 `user_id`。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| user_id | 用户唯一标识 | String | 主键，带索引，形如 u_xxxxxxxx |
| nickname | 昵称 | String | 非空，长度 2–20 |
| avatar | 头像地址 | String | 默认空串 |
| username | 登录账号 | String | 带索引，默认空串，应用层保证唯一 |
| password_hash | 密码摘要 | String | 默认空串，PBKDF2 不可逆存储 |
| body_shape | 体型 | String | 默认空串，取值见规则库五体型 |
| height_cm | 身高（厘米） | Integer | 默认 0 |
| weight_kg | 体重（千克） | Integer | 默认 0 |
| shoulder_width | 肩宽描述 | String | 默认空串 |
| waist | 腰围描述 | String | 默认空串 |
| hip | 臀围描述 | String | 默认空串 |
| city | 常用城市 | String | 默认空串 |
| gender | 性别 | String | 默认空串 |
| styles | 常用风格，多选 | JSON | 默认空数组 |
| pref_color | 色彩偏好 | Integer | 默认 5，范围 1–10 |
| pref_style | 风格偏好 | Integer | 默认 5，范围 1–10 |
| pref_comfort | 舒适偏好 | Integer | 默认 5，范围 1–10 |
| pref_occasion | 场合偏好 | Integer | 默认 5，范围 1–10 |
| pref_fabric | 面料偏好 | Integer | 默认 5，范围 1–10 |
| created_at | 创建时间 | DateTime | 默认当前 UTC 时间 |
| updated_at | 更新时间 | DateTime | 默认当前时间，更新时自动刷新 |

## 二、clothing_items 衣物单品表

存储用户衣橱中的每件单品。主键 `item_id`，按 `user_id` 归属。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| item_id | 单品唯一标识 | String | 主键，带索引，形如 i_xxxxxxxx |
| user_id | 所属用户 | String | 带索引，非空 |
| name | 单品名称 | String | 非空，长度 1–50 |
| category | 一级品类 | String | 非空，上装/下装/外套/鞋/连衣裙/配饰等 |
| sub_category | 二级品类 | String | 非空，如衬衫、牛仔裤 |
| color | 颜色 | String | 默认空串，取值见标签枚举 |
| color_brightness | 色彩明暗 | String | 默认空串，亮色/暗色 |
| season | 适用季节 | String | 默认“四季” |
| fit_snug | 合体度 | String | 默认空串，修身/合身/宽松/Oversize |
| fit_silhouette | 廓形 | String | 默认空串，直筒/收腰/A 字等 |
| fabric | 面料 | String | 默认空串 |
| style | 风格 | String | 默认空串 |
| occasion | 适用场合，多选 | JSON | 默认空数组，如 ["通勤","上课"] |
| warmth_level | 暖度等级 | Integer | 默认 3，范围 1–5 |
| formality_level | 正式度等级 | Integer | 默认 3，范围 1–5 |
| image_url | 图片地址 | String | 默认空串 |
| tags | 标签，多选 | JSON | 默认空数组 |
| created_at | 创建时间 | DateTime | 默认当前时间 |
| updated_at | 更新时间 | DateTime | 默认当前时间，更新时自动刷新 |

## 三、chat_sessions 对话会话表

存储一次连续对话的上下文与额度。主键 `session_id`。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| session_id | 会话唯一标识 | String | 主键，带索引，形如 s_xxxxxxxx |
| user_id | 所属用户 | String | 带索引，非空 |
| status | 会话状态 | String | 默认 active，active/ended |
| occasion | 场合 | String | 默认空串 |
| weather_city | 天气城市 | String | 默认空串 |
| weather_temp | 温度 | Float | 默认 22，允许为空表示天气未知 |
| weather_rain | 降雨描述 | String | 默认“未知” |
| weather_rain_prob | 降雨概率 | Float | 可空，范围 0–100 |
| weather_source | 天气来源 | String | 默认空串，passed/realtime/unavailable |
| temp_pref_color | 临时色彩偏好 | String | 默认空串，亮色/暗色 |
| temp_pref_style | 临时款式偏好 | String | 默认空串，基础款/设计款 |
| constraints | 约束集合 | JSON | 默认空对象，含 exclude_colors、replace |
| shown_outfit_ids | 已展示方案标识 | JSON | 默认空数组，用于去重 |
| remaining_count | 剩余推荐额度 | Integer | 默认 15 |
| created_at | 创建时间 | DateTime | 默认当前时间 |
| updated_at | 更新时间 | DateTime | 默认当前时间，更新时自动刷新 |

## 四、chat_messages 对话消息表

存储会话中的每一条消息。主键 `message_id`，外键 `session_id` 关联会话表。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| message_id | 消息唯一标识 | String | 主键，带索引，形如 m_xxxxxxxx |
| session_id | 所属会话 | String | 外键，带索引，非空 |
| role | 消息角色 | String | 非空，user/agent |
| action | 动作类型 | String | 默认 free_text |
| content | 文本内容 | String | 默认空串 |
| outfits | 关联方案标识 | JSON | 默认空数组 |
| payload | 原始请求或响应载荷 | JSON | 默认空对象 |
| created_at | 创建时间 | DateTime | 默认当前时间 |

## 五、feedback_records 反馈记录表

存储用户对方案的反馈及偏好增量。主键 `record_id`。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| record_id | 反馈唯一标识 | String | 主键，带索引，形如 r_xxxxxxxx |
| user_id | 所属用户 | String | 带索引，非空 |
| session_id | 关联会话 | String | 默认空串 |
| outfit_id | 关联方案 | String | 默认空串 |
| rating | 评级 | Integer | 默认 1，2=喜欢、1=一般、0=不喜欢 |
| tags | 反馈标签 | JSON | 默认空数组 |
| comment | 文字评论 | String | 默认空串 |
| evidence | 偏好增量与撤销标记 | JSON | 默认空对象 |
| created_at | 创建时间 | DateTime | 默认当前时间 |

## 六、purchase_evaluations 购前评估记录表

存储每次新品评估的目标与结果。主键 `evaluation_id`。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| evaluation_id | 评估唯一标识 | String | 主键，带索引，形如 e_xxxxxxxx |
| user_id | 所属用户 | String | 带索引，非空 |
| target_item | 拟购单品快照 | JSON | 默认空对象 |
| result | 评估结果 | JSON | 默认空对象 |
| created_at | 创建时间 | DateTime | 默认当前时间 |

## 七、outfit_records 搭配方案记录表

存储生成方案的快照，支持会话内去重与历史回溯。主键 `outfit_id`。

| 字段 | 含义 | 类型 | 约束 / 默认 |
|---|---|---|---|
| outfit_id | 方案唯一标识 | String | 主键，带索引 |
| user_id | 所属用户 | String | 带索引，非空 |
| session_id | 关联会话 | String | 带索引，非空 |
| items | 方案包含的单品快照 | JSON | 默认空数组 |
| score | 方案得分 | Float | 默认 0.0 |
| reason_summary | 理由摘要 | String | 默认空串 |
| reason_points | 理由点列表 | JSON | 默认空数组 |
| is_diff | 是否差异化方案 | Integer | 默认 1，取值 0/1 |
| created_at | 创建时间 | DateTime | 默认当前时间 |

## 八、表级汇总

| 表名 | 中文名称 | 主键 | 显式外键 | 记录粒度 |
|---|---|---|---|---|
| users | 用户表 | user_id | 无 | 一个用户一行 |
| clothing_items | 衣物单品表 | item_id | 无 | 一件单品一行 |
| chat_sessions | 会话表 | session_id | 无 | 一次会话一行 |
| chat_messages | 消息表 | message_id | session_id | 一条消息一行 |
| feedback_records | 反馈记录表 | record_id | 无 | 一条反馈一行 |
| purchase_evaluations | 购前评估表 | evaluation_id | 无 | 一次评估一行 |
| outfit_records | 方案记录表 | outfit_id | 无 | 一套方案一行 |
